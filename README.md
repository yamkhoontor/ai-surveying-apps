# AI for Surveying and Geomatics — Companion Apps

Three browser apps that train real AI models on simulated survey data, for the book *AI for Surveying and Geomatics: A Practical Guide for Surveyors and Engineers* by Yam Khoon Tor.

- **App 1 — Point Cloud Classification Lab** (Chapter 7)
- **App 2 — GNSS Urban Canyon** (Chapter 9)
- **App 3 — Learn the Normal** (Chapter 10)

**Online:** https://yamkhoontor.github.io/ai-surveying-apps/

**Offline:** click *Code → Download ZIP*, unzip, and open `index.html` in any web browser. No installation or internet connection is needed.
